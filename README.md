# Movie Recommendation & IPL Streamlit App

This repository contains a Streamlit application featuring:
1. Favorite IPL Team (Mumbai Indians) overview and logo.
2. 5 Trending Bollywood Movie recommendations with posters and descriptions.

## Local Setup
```bash
python -m venv venv
.\venv\Scripts\pip.exe install -r requirements.txt
streamlit run streamlit_app.py
```
